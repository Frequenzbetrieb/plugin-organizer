# Changelog

All changes to the Frequenzbetrieb Plugin Organizer. Downloads for every version: [Releases](https://github.com/Frequenzbetrieb/plugin-organizer/releases).

## [0.11.0] – 2026-10-13
- **Quick search over Live:** a global key (default ⌃⌥Space) opens a small search window over Live – type, Enter loads, ⇧ new track, ⌥ replace. Without typing: recent and most loaded, chains.
- **Recently / most loaded:** as a sort order, in the quick search, on the Stream Deck and on your phone.
- **Typo-tolerant search:** “proq” finds Pro-Q 3, “valhala” finds Valhalla; also searches tags and notes, best matches first.
- **Chains everywhere:** drag them onto keys of the on-screen keyboard, use them on the Stream Deck (overview and “Load plugin”) and on your phone.
- **Notes & tags** per plugin (right-click), tag filter in the left sidebar.
- **“Used in which Live sets?”** in the right-click menu – shows which sets use a plugin.
- **Replace device:** ⌥-click or right-click swaps the device selected in Live in the same place (Live script required).
- **Pictures for racks & presets** from favourites, collections, chains and keys via “All pictures” or right-click.
- Backups now also include chains, ratings, notes, tags and language.

## [0.10.0] – 2026-10-13

## [0.9.1] – 2026-10-13

## [0.9.0] – 2026-10-13
- **Chains:** save several plugins as a chain (right-click → “Add to chain”, order via ⌘-click) and load them onto a track one after another with one click; ⇧-click on a new track. Change the order by right-clicking the chain.
- **Rating:** 1–5 stars per plugin via right-click, shown on the tile, sort order “Rating”.
