        Kostenlos & Open Source von Frequenzbetrieb n.e.V.

        So geht's

        Karte auf eine Taste ziehen, oder Rechtsklick auf eine Karte → „Taste zuweisen …“ und Taste drücken.

        Rechtsklick auf eine belegte Taste: „Auf neuer Spur laden“ – dann legt die Taste in Live erst eine neue Spur an (MIDI für Instrumente, Audio für Effekte) und lädt das Plugin dort.

        ⇧-Klick auf eine Karte lädt ebenfalls auf eine neue Spur.

        Laden wartet, bis es fertig ist
        Einstellungen
        Ein-/Ausblenden-TasteGlobal: blendet die App aus und holt sie wieder nach vorne. Klick ins Feld, dann Taste(n) drücken.
        Version Nach einer neuen Version suchen.
        Stream DeckPlugins mit Bild auf den Tasten, ein Druck lädt sie in Live. Stream-Deck-Plugin herunterladen und per Doppelklick installieren, dann in der Elgato-Software die Aktion „Plugin laden“ (Kategorie Frequenzbetrieb) auf eine Taste ziehen.

        Frequenzbetrieb Plugin Organizer
        Ein kostenloses Open-Source-Projekt von Frequenzbetrieb n.e.V. – frei nutzbar unter der AGPL-3.0. Wenn dir das Programm hilft, freuen wir uns über eine Spende für die Vereinsarbeit.
