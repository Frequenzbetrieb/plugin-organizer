        So geht's

        Karte auf eine Taste ziehen, oder Rechtsklick auf eine Karte → „Taste zuweisen …“ und Taste drücken.

        Rechtsklick auf eine belegte Taste: „Auf neuer Spur laden“ – dann legt die Taste in Live erst eine neue Spur an (MIDI für Instrumente, Audio für Effekte) und lädt das Plugin dort.

        ⇧-Klick auf eine Karte lädt ebenfalls auf eine neue Spur.

        Laden wartet, bis es fertig ist
        Live-Skript einrichten

        Mit dem Live-Skript lädt der Plugin Organizer Plugins, Devices, Racks und Presets direkt über Ableton Live – in Sekundenbruchteilen und genau das richtige Gerät. Das Skript ist schon installiert; Live muss es nur einmal aktivieren:

        1. Live neu starten. Set speichern, Live beenden und wieder öffnen – Live liest Skripte nur beim Start ein.
        2. Einstellungen öffnen: in Live ⌘ , (Windows: Strg ,) → Reiter „Link, Tempo & MIDI“.
        3. Control Surface wählen: in einer freien Zeile unter „Control Surface“ „Frequenzbetrieb“ auswählen. Input und Output bleiben auf „None“.
        4. Fertig. Einstellungen schließen – hier erscheint dann ✓.
        Warte auf Live …
        Einstellungen
        Ein-/Ausblenden-TasteGlobal: blendet die App aus und holt sie wieder nach vorne. Klick ins Feld, dann Taste(n) drücken.
        SpracheSprache der App. „Automatisch“ folgt der Systemsprache.
        Live-SkriptPrüfe …
        Nur wer diesen Code hat, kommt hinein. macOS fragt beim ersten Mal, ob eingehende Verbindungen erlaubt sind – „Erlauben“ wählen.
        Sichern & übertragenTasten, Favoriten, Sammlungen, Kategorien, eigene Bilder, Plugin-Bilder und Einstellungen in einer Datei – zum Sichern oder für einen anderen Rechner.
        WerkseinstellungenLöscht Plugin-Liste, alle Bilder, Tasten, Sammlungen und Einstellungen und startet neu wie frisch installiert. Mit Sicherheitsabfrage, auf Wunsch vorher Sicherung.
        Version Nach einer neuen Version suchen.
        Stream DeckPlugins mit Bild auf den Tasten, ein Druck lädt sie in Live. Stream-Deck-Plugin herunterladen und per Doppelklick installieren, dann in der Elgato-Software die Aktion „Plugin laden“ (Kategorie Frequenzbetrieb) auf eine Taste ziehen.
